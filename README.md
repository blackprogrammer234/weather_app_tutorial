# weather_tracker_v1
Brief Description

A simple Flutter application that displays the current weather based on your location. This app leverages geolocation, a weather API, and the BLoC (Business Logic Component) package to manage the business logic efficiently.

## About the Project

The waether tracker app was created to brush up on implementing the BLoC pattern for handling the business logic layer and to demonstrate how to integrate geolocation and weather APIs in a Flutter project. The app serves as both a practical tool and a tutorial for others curious about building similar functionality.

## Features

    - Retrieves the user's current location using geolocation.
    - Fetches real-time weather data from a weather API.
    - Implements the BLoC architecture for clean and scalable business logic.
    - Uses environment variables to manage sensitive information securely.
